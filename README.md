# 📚 MedQ

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

Ferramenta para acompanhar os estudos de um aluno e gerar relatórios sobre seu progresso durante o processo de elaboração de questões.

## 🧠 Sobre o projeto

O MedQ ajuda a registrar o histórico de estudo de um aluno e produz relatórios que resumem esse acompanhamento, servindo como apoio no processo de criação de questões.
